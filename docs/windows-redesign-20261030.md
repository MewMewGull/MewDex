# Windows 工作台改造（2026-10-30）

以日常对话为主界面。设备、工作区和对话形成导航层级；字体、配对管理和运行记录放在设置或二级入口。手机继续只作为输入端，虚拟宠物和 Dot 不在本轮范围内。

| 反馈 | 本轮实现 |
| --- | --- |
| 1. 历史不能滚轮滚动 | 对话区独立滚动，靠近顶部自动读取更早事件并保持阅读锚点。历史页面与实时事件合并；SDK 的实时窗口裁剪不再删除当前已读入的内容。搜索结果向上下连续读取，保留回到最新入口。 |
| 2. 没有外观选项 | 左下角账号菜单 → 设置 → 外观；支持系统/深色/浅色、字体、界面字号、对话字号、强调色和动效开关，立即生效并保存在本机。 |
| 3. 没有动效 | 对话消息、弹窗、账号菜单、文件面板以及按钮反馈加入短时过渡；尊重系统减少动态效果设置。 |
| 4. 不能创建或分类工作区 | 左栏“工作区”打开设备目录浏览，可添加已有目录或创建项目文件夹，填写名称与分类；已添加项目可“整理”名称与分类。工作区实时保存至执行端，原对话的目录绑定保持。左栏按分类、工作区展示对话，搜索会展开命中分组。 |
| 5. 左上角无效图标 | 移除侧栏装饰图标，只保留 MewDex 名称。 |
| 6. 输入区缺少控制与上下文 | 常驻模型、思考强度、任务策略和访问权限选择；上下文展示最近请求的实际 token 用量及模型窗口比例。更多策略仍进入完整设置。 |
| 7. 文件查看器难用 | 改为停靠在右侧的文件面板。左键用默认应用打开；右键选择检测到的 IDE、系统打开方式、文件资源管理器或应用内预览，并能为工作区保存默认应用。远程文件下载为本机副本，明确不自动同步。取消“快照”产品术语。 |
| 8. 账号区域内容不当 | 左下角展示本机执行服务的模型账号；本机不在当前网络时使用选中设备的账号。菜单集中登录状态、额度、设置和退出模型账号。 |
| 9. 网络任务含义不清 | 改为“任务与请求”，主入口只统计在线设备当前执行或等待回复/排队的任务。离线、旧执行及结果待确认的记录放在“历史待确认”，不删除原记录。 |
| 10. 切换对话连接状态闪烁 | 选择对话引发的初始订阅不再改写已建立的全局连接状态，真实断连与重连仍反映。 |
| 11. 首字前没有工作提示 | 点击发送立即显示正在提交状态，执行端进入 running 后显示思考/处理动画；等待用户回复时使用已有请求提示。 |
| 12. 侧栏宽度固定 | 拖动侧栏边缘调整 220–440px，支持方向键、双击还原，宽度保存在本机。 |

## 引擎与设备数据

- 账号资料来自 `account/read`；只有管理员可读取账号、额度、发起登录或退出登录。只投影邮箱、账号类型和计划，不返回凭据。固定版协议没有账号头像字段，因此使用邮箱首字母，不生成或冒用真实头像。
- 额度来自 `account/rateLimits/read`，显示每个窗口的剩余百分比及重置时间；未提供数据时明确说明，不显示虚构的 0% 或 100%。
- 上下文来自 `thread/tokenUsage/updated` 的 `last` 和 `modelContextWindow`，与账号额度分开。
- 访问模式为只读、工作区读写、工作区读写与网络。选择实际改变执行权限配置；正在运行的回合保持原权限，下一回合在原引擎对话上恢复并确认新配置。额外授权继续使用原请求机制，私有设备数据仍排除。
- `workspace.browse/create/update` 仅限管理员。项目目录与原会话身份不由名称、分类修改而改变；新目录列表通过持久事件投影到 Hub，节点重连与心跳使用最新目录。
- 本机文件路径由本机保存的设备和项目确定，原生桥只接收工作区相对位置。Windows 打开方式调用系统选择器；IDE 列表来自本机注册表和安装位置。远程文件副本独立保存，打开本机副本不会写回远端。

官方协议参考：[Codex App Server](https://learn.chatgpt.com/docs/app-server)。

## 测试包与切换

Windows 测试包放在 `dist/windows`，完整解压后运行 `mewdex-client.exe`。先从系统托盘退出旧工作台，避免单实例机制仅唤起旧窗口。

本轮包含新版后台组件，但导出和启动工作台不会自动替换正在运行的服务。需要测试工作区创建、额度与权限功能时：

1. 等现有任务结束后，在新版的“设置 → 通用 → 本机设备”停止本机服务。
2. 如果启用了自动启动，进入“自动启动”点击“重新核对并启用”，使登记入口引用新版组件。
3. 回到本机概览启动服务，再刷新工作台。

远端设备需要各自更新执行器后才会声明新增能力；本轮不替换 Mac 或服务器进程，不修改登录账号及 HTTPS/回程配置。
