# Windows 桌面体验

当前开发优先级是 Windows 桌面本体。其他平台继续共用协议、SDK 与界面组件，移动端和 Linux 的打包验证随后集中进行。

## 一级界面

侧栏上方显示当前设备与新对话，主体按分类和工作区组织对话，可折叠、搜索并在指定工作区新建对话。“工作区”入口浏览各设备目录、添加已有目录、创建项目文件夹及整理名称与分类。侧栏边缘支持拖宽并保存。归档对话从日常列表收起，当前打开的归档内容仍保留导航位置。

设备选择器与快速切换共用设备排序、系统名称和状态说明：保留当前设备在前，之后优先有可见项目的执行设备，再按在线状态与名称排列。首次连接没有可恢复位置时也使用同一排序，不直接选择网络列表的第一项。未开启执行能力或没有可用项目的设备仍可选择查看历史，并明确标注原因。设备搜索支持名称、系统名称及空格组合关键词，macOS 与原平台名称均可查找。

设备选择器的搜索框支持方向键选择、Enter 打开和 Escape 关闭，与 Ctrl+K 共用键盘列表逻辑；结果按设备编号保留当前高亮，设备状态刷新与重排时不跳到另一台。选定目标后沿用原输入聚焦入口，取消则返回原触发处；输入法组词和修饰组合键不触发列表打开动作。主侧栏只显示当前设备，详细能力与系统信息留在选择界面。

对话搜索也匹配项目名与设备名，可用空格组合多个关键词，忽略大小写；仍在当前选定的设备/全部/未读范围内查找。多项目设备、跨设备列表与搜索结果显示所需的项目上下文，单项目设备的日常列表保持简洁，完整名称可悬停查看。归档页共用同一搜索规则。

侧栏对话支持右键或系统菜单键打开整理菜单，查看目标设备与项目并进行重命名、置顶、归档/恢复。菜单按指针位置显示，键盘选择、Escape 与焦点行为使用共享组件；打开菜单不切换正在阅读的对话。重命名沿用原窗口，关闭后可回到原列表项；更新失败在原目标旁显示，可关闭提示。菜单与顶部对话选项共用操作文字、图标和状态，不增加常驻管理按钮。

新回复以侧栏圆点和稍亮的标题提示，“未读”筛选覆盖所有已授权设备，归档对话有新回复时也可从这里进入；当前对话读完后暂留在筛选中，避免导航位置跳动。Ctrl+K 同样标记未读，阅读旧消息时可直接“查看新回复”。未读表示有尚未读到的完整模型文字，与任务与请求中的待回复请求、未知结果和执行状态分别展示。

已读位置按当前网络和输入身份保存在本机，不跨输入设备同步。首次启用从当前历史开始，已有旧记录不会全部标成未读；重开应用或重连后补齐此后新增的回复。只有窗口位于前台、最新消息已呈现且阅读区到达底部时才标记已读，历史浏览、后台窗口和弹窗遮挡期间继续保留标记。退出配对或访问范围改变时与原私有视图一起清除，不恢复或发送输入。

网络存在活动任务时，侧栏显示紧凑的“任务与请求”入口与待处理/进行中数量。没有任务时不占用该位置；对话选项和 Ctrl+Shift+J 仍可打开概览。详细状态留在二级界面，不把每台设备的队列和请求铺到主对话区。

主区呈现当前设备、对话、执行状态、消息与输入区。Markdown 标题、列表、表格与代码块直接排版；代码块和消息均可复制。连续工具活动默认收起，错误消息与当前需要用户处理的请求保留可见。阅读较早内容时不随新消息强制滚动，可通过“回到最新”继续跟随。

本次窗口内，各对话分别保留历史页、阅读锚点、滚动偏移和工具展开状态，切换设备或对话后可回到刚才读到的位置。离开时跟随最新的对话继续跟随，正在读旧内容的对话按原消息事件读取，避免新消息将旧位置挤出最近记录。恢复等待目标记录呈现，不重新聚焦旧搜索结果，完成前不标记已读；“回到最新”、发送消息和主动定位当前请求会覆盖旧阅读位置。位置只留在本次工作台内存，退出或访问范围改变时清除；重开应用仍使用已有的工作位置设置。

执行端提供计划时，对话尾部显示折叠的任务计划卡片，摘要只展示已完成数量、当前步骤与回合状态。展开后查看说明及完整步骤，长计划在卡片内滚动；未产生计划的新对话不预留空面板。计划只展示执行端已经报告的步骤，不生成百分比、剩余时间或新的执行操作。新回合没有计划时收起上一轮的计划，返回旧历史页仍可查看当时记录。

历史计划按当前历史页末尾的事件位置读取，翻页期间不短暂混入最新计划。离线和待核实执行保留最后步骤，区别于实时执行中；暂停与结果未知分别显示。回合结束不会自动将未完成步骤打勾。计划查询直接读 Hub 的持久事件，不受界面最近事件窗口限制，执行设备离线也可读取；旧 Hub 没有声明此能力时不显示入口。

输入区保留附件、项目选择、发送、执行中的停止，以及当前需要的排队操作。文本与附件引用按网络、输入身份、设备和对话保存在本机输入应用的存储中，重开应用后可继续编辑；附件文件仍由 Hub 保存，不重复存放二进制。新对话创建后草稿转入新会话，回执完成时只清除本次发送的文本和附件。离线设备允许编辑草稿，发送与键盘提交采用相同的可用条件。恢复草稿不会发起指令；本机保存失败会明确提示，读回失败时保留原记录。

运行中且原回合可追加时，主发送按钮显示“追加”，辅助说明和快捷键提示同步说明追加到当前任务；“排入下一条”继续作为单独操作。队列冻结时改为“加入暂停队列”，说明消息只保存到队列、需要手动恢复。正在停止、执行状态未知或尚无有效回合时，普通发送暂停并说明原因，不把回车改为排队操作。归档与旧执行结束继续遵循原恢复/新建入口，后台进程仍在运行时保留原新回合与排队选择。

发送过程中主按钮显示等待标记；输入区继续使用原草稿编辑、选区和附件归属。`ConversationComposer` 共用文字输入、附件选择/粘贴、操作栏与提示，网络投递仍由工作台控制。设备和项目始终出现在原简短上下文中，长名称截断后可悬停查看；管理信息没有进入主操作栏。

执行目标按当前可见的设备角色和原项目判断。没有设备、设备未开启执行能力或原项目不可用时，状态与输入区说明原因，发送和新增附件暂停；缺设备或项目的原文字仍可选择复制，不会转入另一个项目。离线但项目仍可用的设备可以继续编辑草稿；已结束的旧执行也保留原输入供复制。空项目选择器显示原因，拖入文件时的临时提示与附件按钮使用同一条件。

新对话没有执行目标时，空白页提供设备/项目选择；当前网络没有执行设备时，桌面可进入“配置这台电脑”，管理员也可直接进入添加执行设备的配对页，预选执行端角色但不自动生成配对码。普通输入端显示申请设备和项目访问的说明。目标正常时不增加这些管理按钮，完整管理仍留在二级窗口。

发送等待与错误提示分别属于原草稿，一台设备等待回执时可以切到其他设备或对话继续发送；同一草稿仍防止重复提交。新对话建立时，等待状态跟随草稿转入该对话，不把当前导航强行切回。查询待确认回执或显式清除本次输入时，也只处理原草稿的已发送内容，保留之后修改的文字与新附件；执行器的项目排他和未知结果限制继续生效。

新对话的项目选择按设备分别记忆，切换设备后可以继续编辑对应项目的草稿；从已有对话新建时沿用当前项目。输入框随内容自动增高，到达窗口相关的高度上限后在框内滚动，宽度变化也会重新排版。重复选择当前设备或当前对话只返回输入位置，不重新建立选择版本。

本次工作台内，各草稿分别保留输入光标、选区方向和输入框滚动位置。设备、项目、对话切换前采集原输入状态，返回时在自动高度调整后恢复；尚无位置记录的草稿从文字末尾继续。聚焦输入保留内部滚动，新对话成立时编辑位置跟随原草稿迁移。这里只记数字位置，不额外复制正文或写入本机存储，清空草稿、退出配对和访问范围清除时一同释放，重开应用从持久文字恢复。

Windows 支持向对话区域拖入文件，也可在输入框中粘贴剪贴板图片或文件；普通文本粘贴保留原行为。拖入时临时显示目标设备和对话，放开后复用原附件上传接口。多批附件进入同一上传队列，每个文件单独显示等待、上传、已上传待处理或失败，并可取消、移除或重试；上传过程中也可继续添加。

上传按原设备、项目和草稿保存归属，切换设备或对话后继续，完成后加入原草稿；其他对话可以照常发送。任务最多同时传两个文件，加入草稿时保持用户的选择顺序，避免图片等附件因完成先后而换位。单个失败或超限文件不阻止其他文件传输，失败项需重试或移除后才可发送原草稿。尚在等待前项处理的已上传文件明确显示状态，不静默丢掉未完成的附件。

新对话建立时，文本草稿与尚在上传的文件一起转入该对话；回执恢复采用同一移动入口。导航和项目选择会标记包含待处理附件的草稿。输入区的上传项与已上传附件共用一个有高度上限的滚动区域，文件增多时保持文本框和操作栏可用。上传中的源文件只留在本次应用，真正退出后需重新选择；成功加入草稿的附件引用继续使用原本机保存。取消终止当前请求并移除本次选择，原 Hub 中已收下的文件不由此删除。

草稿和历史消息共用附件卡片，以文件名和大小展示。点击后按需读取附件：图片在窗口中查看，文本预览前 256 KiB；预览内容可复制，完整文件通过 Windows 系统保存对话框保存。文件读取复用 Hub 的现有授权，SDK 与本机保存适配器分别处理网络和文件写入，凭据不进入链接或保存命令。预览关闭时释放图片对象和临时内容。网页形态显示“已开始下载”，Windows 保存完成后才显示“已保存”。

文本文件预览提供行号、自动换行和就近查找，复用输出查找栏；Ctrl+F 打开，Enter / Shift+Enter 在匹配行之间移动，Escape 先关闭查找。窗口标题、文件信息和复制/保存操作固定，正文独立滚动。编码默认按 BOM 识别 UTF-8、UTF-16 LE/BE，也可在预览内选择 UTF-8、UTF-16 或 GB18030/GBK。切换编码重新解码已读字节，复制取得对应文字，保存沿用原始文件内容；较大文件截断预览时略去末尾尚不完整的字符。

当前阻塞请求会在对话状态中显示“等待回复”，输入区提供定位入口。提问支持多行回答与 Ctrl+Enter 提交，授权按钮区分单次操作和本回合权限。回复结果未知时按原回执查询，不重新提交答案；明确失败后可重新填写。访问放行仍使用执行端提供的 `canAccept` 与原权限范围。

表单数字以原始输入暂存，负号、小数和科学记数法可以逐步编辑，切换对话后仍保留填写过程。提交时才转换数字并核对整数、必填及范围，错误标在对应字段并聚焦第一项；修改只清除该字段的标记。可选数字留空时不发送这个字段，零和 false 保持原值，普通文字的空白不改写。拒绝表单只发送拒绝动作。

单行回答中的普通 Enter 留在编辑，使用发送按钮或 Ctrl+Enter 提交；多行回答继续用 Enter 换行。当前可回复的表单显示简短键盘提示，组词期间不触发快捷提交。

浏览历史时不把当前请求表单接在旧记录后，输入区仅提示当前待处理数量；点击“返回当前”先回到最新记录，再定位请求区。从任务与请求打开待回复会话使用同一路径，等待该对话的历史与请求读取完成后再定位。定位只聚焦请求区域，不自动聚焦接受按钮，也不先聚焦普通输入框；用户切换设备、对话或历史位置后取消旧定位。设备网络未连接时，缓存请求保留可读，回复按钮暂停使用。

补充问题和表单的未发送答案在本次工作台内按原设备、对话和请求暂存，切换设备或对话后再回来可继续填写，不因切换自动提交。正在发送、回复已提交和结果待确认也跟随原请求，离开页面不重置发送状态。完成后只使原对话的请求查询失效；明确失败后保留原填写内容供修改，结果未知时清除答案并保留原回执供读取，避免再次提交。

输入端的这份答复暂存只在本次应用内存中，不写入本机草稿、Hub 回执或持久存储；重开应用不会恢复表单答案。请求处理或过期后，从当前请求列表确认移除时清除对应暂存；退出或访问范围变化时全部清除。待确认操作窗口查询同一回复回执时，也会同步原卡片的状态。

左下角显示本机模型服务的账号状态，本机不在当前网络时显示选中设备。账号菜单集中登录、额度、设置与退出登录；只有管理员可读取账号资料与额度。输入区将操作压缩为一行：附件、项目、权限、策略用图标，右侧显示上下文图标与模型/强度。新对话的选择用于本次发送，不增加待生效提示；执行中的调整在悬停说明范围，完整项目指令仍放在策略设置。

设备网络断开时继续显示现有对话并允许编辑草稿，恢复同步后再发送；设备卡片、选择器和快速切换中的缓存状态标为“上次在线 / 上次离线”，状态圆点及历史执行提示不继续表示实时在线。超过短暂重连时间才显示紧凑提示，恢复后收起。网络读取自动重试，手动重试和本机服务管理就近提供，地址与原始错误在展开详情中查看。

当前对话与设置共用账号查询和本次登录提示，SDK 提供状态读取、准备设备码登录和取消登录的方法。状态查询不刷新模型凭据；只有用户主动选择登录才开始网页登录流程。设置中的一次性代码和链接留在二级页面，无需官方 App。等待登录时定时读取状态，已登录后清除本次登录提示；完整人工授权过程仍需后续联调。

## 二级界面

Ctrl+K 的快速切换按执行设备、对话和项目组织。设备入口提前展示，当前设备有简短标记；未输入关键词时展示最近 12 条对话及当前设备的项目，数量提示可见。输入关键词后查询所有已载入的授权对话与项目，包含归档内容，不再截取前 20 条匹配。每条对话带设备与项目，便于区分同名工作。

选择项目直接进入指定设备和项目的新对话位置；已有未发送内容时显示“继续草稿”，沿用同一份草稿，不立即创建会话或开始执行。此入口与项目选择器、草稿页的继续编辑共用导航。结果刷新或重新排序时按目标编号保留键盘选择，空结果没有可提交选项；明确选择后聚焦输入，取消则沿用弹窗的焦点恢复。

窗口右上角的对话选项提供重命名、置顶、归档/恢复，以及执行策略、终端、差异和排队历史。已归档对话在同一菜单的二级列表中搜索、查看和恢复，Ctrl+K 输入搜索时也会包含归档内容。归档后继续保留正文、原回执和执行状态，正在执行的任务及已有队列继续；恢复后可追加消息。主区只显示仍需处理的队列。终端和差异在同一输出面板切换，宽桌面窗口使用并排布局。

待确认操作也集中在二级窗口，输入区只保留一条数量与“查看操作”入口，不铺开操作编号、逐条查询说明和分页按钮。对话选项可随时打开此窗口，包括尚未建立对话的情况；没有待处理项时主区不占位。已进入待确认流程的发送或控制结果使用这一入口，明确失败和普通错误仍就近显示。

窗口按设备分组，当前设备靠前；每项标明原对话或新对话项目，有权访问的原对话可直接打开。其他设备只显示本次输入暂存的操作，不把当前设备的分页当作全网完整列表。刷新、查询原回执、返回首页和后续分页都留在窗口内，编号默认折叠。关闭窗口继续保留记录；显式关闭单项提示沿用原语义，本机有提交快照时才提供清除本次输入的文案。列表查询和打开原对话均不重发指令。

执行策略中的“模型与推理”读取当前执行设备的模型目录，支持分页、刷新、模型说明和自定义名称。选择具体模型后显示它提供的推理强度，目录中新出现的强度沿用原名称，不在输入端写死取值。更换模型时保留它支持的原强度，否则回到执行端决定；保留未出现在目录中的已有设置供查看和修改。模型和强度与原策略一起保存，已有对话在下一回合生效。

执行策略增加独立的“协作方式”：直接工作或先讨论方案。方案讨论先调查、补充需要的信息并提出可审阅方案，确认后切换为直接工作；验证范围和不要测试仍分别设置。设置需要当前 Hub 与执行端都声明支持，旧设备不新增可选项。方案讨论生效时，输入区仅提示当前方式，完整选择、说明与历史仍留在策略窗口。方案讨论属于引擎模式及任务指令，项目的实际执行权限保持原配置。

协作方式与策略版本一起保存，已有对话在下一回合生效，队列保留入队时的方式，后续编辑不改写旧输入。历史版本显示方案讨论标记，恢复时沿用当时的方式与完整指令；切换方式不新建或分叉对话。

策略窗口复用通用设置框架，固定显示目标设备、当前对话、分类和底部操作，中间内容独立滚动；应用与保存错误不会跟随长表单离开可视区域。分类可用左右方向键和 Home / End 切换，跳过不可用的版本历史入口。基础指令替换收在高级选项，已有自定义状态保留简短标记。预览在独立阅读区呈现当前生成的任务指令，可返回修改或应用；来源与历史共用同一正文复制组件。历史先显示协作方式、验证范围、时间与当前版本，完整版本编号和当时的指令按需展开；离线来源与空历史分别说明状态。

未应用的策略填写按设备、项目和对话保留在本次工作台内存，关闭设置或切换目标后可继续填写；退出工作台不保留。操作栏明确标记未应用，更改只在用户主动应用或保存后生效。“还原填写”放弃当前未应用内容并使用当前已应用的策略；其他输入端更新过版本时保留填写及原参考版本，并提示可以载入最新策略，保存仍由原版本规则核对。保存、恢复、预览的等待和错误各归原目标，另一台设备可继续编辑；成功只清除原提交快照，不关闭或改写后来打开的其他编辑页。退出配对或访问范围变化时清除这些暂存及等待反馈。

目录中的推荐项与会话或执行端实际继承的模型分别表示。尚不确定继承模型时，由执行端决定强度；明确选择模型后再查看相应选项，不借用推荐项来推断当前配置。目录用于展示选择，不表示账号已取得访问权限。未升级的执行设备仍可手动填写模型，强度设置按设备声明的能力显示，不自动升级其他设备。

“项目文件”打开停靠在右侧的目录面板，对话和输入区随之收窄，仍可继续输入。目录支持上级、地址、刷新和分页；左键使用工作区默认应用打开文件，右键选择检测到的 IDE、系统打开方式、资源管理器或应用内预览，并可保存此工作区的默认打开方式。“已接收文件”保留原文件副本供离线查看。

当前文件与回传副本分别展示：前者可能已被任务修改，后者保存请求时的内容和校验值。单个文件副本最多 20 MiB，不将目录打包或自动同步整个项目。回传结果待确认时保留原指令编号，查询回执或已有文件副本，不自动再次复制。读取文件不会继续模型回合、解除未知执行或清理项目占用。

消息文件链接左键复用默认应用打开；右键可选择打开方式、在资源管理器显示或进入项目文件面板。中键进入文件面板。本机路径根据保存的设备与项目绑定解析，远程文件先取得本机副本，修改副本不会自动同步。打开失败在文件面板中显示原因。

文件引用中的 `:行:列`、`#L行` 和常见行范围保留起始行；行号不会进入实际路径。应用内文本预览可定位该行，系统默认打开使用应用自身的行为。

对话名称、置顶和归档由 Hub 保存，与执行器状态分开。执行设备离线时，只要 Hub 可连接且身份有访问权，仍可整理对话；后续状态上报、指令回执、历史与实时事件均使用同一显示信息，不覆盖用户的整理设置。多个有权输入端共享这些设置。

已有对话可通过 Ctrl+F 或对话选项中的“查找对话内容”打开搜索。输入关键词并提交后，在 Hub 保存的本对话文字中查找你的消息与完整模型回复，支持中文、词组和忽略大小写；工具输出仍在输出面板查看。结果按最近消息排列，显示角色、时间及带高亮的片段，按需加载更多；输入框与结果之间可用方向键移动。关键词只在当前对话的本次工作台中保留，切换对话后清空，关闭搜索会取消在途读取。

选择结果后关闭搜索，读取对应历史页、居中定位并标记原消息。历史可以继续向更早或较新一页翻阅；输入区附近的“回到最新”也适用于历史浏览，不必先滚回页首。历史页只显示回复的一部分时明确标注，并将复制按钮标为“复制片段”；完整回复快照到达后恢复普通显示。历史浏览继续保留草稿，提交消息时先回到最新视图，再沿用原发送与回执流程。查找和定位本身只读取记录。

宽窗口的输出面板边界可以拖动，聚焦边界后用左右方向键微调，双击恢复默认宽度。拖动时只更新布局，松开后保存比例；取消拖动恢复先前比例。窄窗口继续使用上下布局。

终端按命令编号整理输出，默认跟随最新命令，也可选择某一条或按命令分组查看当前记录中的全部输出。命令区显示原命令、工作目录、退出码和耗时；历史或断线时的执行中状态标为上次状态。工具消息的“查看输出”直接定位对应命令，完整输出快照替换增量片段，避免重复或漏掉历史输出。向上阅读时固定当前命令，后续新命令不会抢走视图；终端内可回到最新位置，再通过选择器恢复跟随最新命令。

输出面板的放大镜或面板内 Ctrl+F 打开就近查找。终端使用当前缓冲区，保留 5000 行滚动记录；支持前后匹配、复制选中文字和完整输出文字，复制时去掉颜色与终端超链接控制码。差异查找按匹配行定位，Enter / Shift+Enter 前后切换，Escape 关闭。输出内容仍来自当前会话的有界记录，历史页显示对应上下文。

本次工作台内，输出的命令选择、终端查找文字与滚动位置，以及差异文件、原始视图、换行、查找和滚动分别随原对话及历史页保留。关闭面板、切换设备或暂时查看另一类输出后可继续阅读；最新记录与旧历史页分别记忆，不把上一页的命令引用带到下一页。主动点击工具输出才处理新的命令定位，恢复旧查找栏不会自动抢走对话输入焦点。正文仍来自原查询，不额外复制或持久保存输出；退出配对或访问范围清除时释放这些阅读状态。

所选命令不在当前记录、或文件不在本次差异时，保留原选择并显示说明，提供手动查看当前最新命令或全部差异的入口；不悄悄改为另一项，也不对缺失项显示复制操作。历史页尚在恢复时显示读取提示，避免短暂展示上一页的输出。

差异按文件组织，提供文件选择、旧/新行号、增删数量、重命名和二进制提示，可切换自动换行或查看原始差异。文件与全部差异均可复制；项目文件入口继续打开现有的作用域文件查看器，主动读取当前文件快照后预览。差异代表引擎报告的回合变更，文件入口读取的则是项目当前内容。目录与文件名作为文字显示，不交给系统命令执行。

任务与请求概览按“全部、待处理、进行中”筛选，可搜索对话、设备与项目，打开后回到原执行对话；有待回复内容时定位请求区域。归档中的活动任务仍然可见，已经明确结束的旧执行留在历史。离线设备显示“设备离线”和上次状态，不用加载动画表示它仍在线执行。概览支持手动刷新，并在状态事件到达后重新读取；非当前对话只传列表刷新提示。

侧栏顶部集中放置新对话、搜索工作台、任务与请求，项目和对话按目录分组。底部放置执行设备、本机设备、设置和账号入口。设置按“工作台、连接、模型与访问”分组，权限相应的管理页面只向管理员显示。通用页包含提醒、键盘说明和工作位置，连接与服务页包含当前连接、网页版开关和本机管理入口。备份、恢复、升级和服务生命周期由本机管理承接。

强调色统一用于选中项、操作链接、重点按钮、焦点边框和搜索高亮，深浅主题分别调整强调文字的对比度。正文和普通分隔线使用中性色，成功、警告、错误和代码增删使用语义色。设置弹窗、对话、文件面板和终端共同复用这些主题变量。

“草稿”页汇总当前网络的本机未发送内容，显示原设备、项目、对话、文字预览、已上传与待处理附件数量；可按内容、附件名、设备和项目搜索，复制完整原文或继续编辑。上传中的文件也会进入列表，按原草稿合并计数；列表不读取附件正文。

继续编辑使用当前可见的设备和对话重新核对目标，恢复原项目与对话位置，保留草稿，不发送消息。归档对话保持归档，旧执行已结束时只提供查看；设备、项目或对话暂不可用时保留原文供复制，不改投另一个项目。切换新对话项目也登记为新的导航选择，防止较早的异步创建结果覆盖用户主动切换。

草稿页继续提供全部清空入口。工作台中移除配对，或在线同步发现访问范围改变时，清除对应的本机草稿；不同网络和输入身份不会共用草稿。

工作位置、各设备的新对话项目、导航展开状态和输出面板比例也按网络与输入身份保存。默认重开后继续上次对话，可在通用设置关闭；先取得 Hub 当前授权快照，只有仍可见的设备与对话才能恢复，已移除的项目回到当前可用项目。位置恢复仅导航和读取数据，不恢复执行或发送消息。用户在加载期间主动选择时优先保留该选择，随后点击通知可正常打开通知目标；通知查询期间手动导航或点击较新通知，较早的查询结果不会改变新位置。

Windows 默认窗口为 1280 × 820，最小为 800 × 640。窗口位置、大小与最大化状态使用 `tauri-plugin-window-state 2.5.0`，重开时保持窗口可见。

系统托盘提供打开工作台与退出工作台。默认关闭窗口时保留输入工作台，继续接收当前网络的消息；通用设置可以关闭此行为。托盘退出只结束输入程序，执行服务由本机管理单独停止。偏好保存在当前用户的应用配置目录，通知点击与再次启动复用同一窗口唤起入口。

## 首次使用与本机管理

Windows 未连接时先选择“在这台电脑开始”或“连接已有网络”。后者只要求网络地址和输入端配对码，输入端名称位于展开设置中。前者打开本机设备管理，读取现有状态后继续已有配置或进行首次配置。

恢复完成后，“数据与更新”按本机角色给出后续步骤：恢复主控网络时先启动并连接本机工作台；恢复远端执行端时先取得执行端配对码，完成网络连接后启动服务。项目核对、模型账号和自动启动只按实际需要列出，旧输入和队列继续保留原状态。入口进入现有概览或连接页，不自动执行后续步骤。

概览与执行端配对页共用 `LocalServiceActions`。配对完成后可在原页启动本机服务；就绪且尚未连接输入端时，再进入该网络的输入配对。执行授权与输入授权分别说明，不把同一个配对码用于两种身份。已在使用的输入连接保持原入口规则，项目编辑或后台操作期间继续沿用原服务按钮限制。

重开已有配对时使用 `useInputConnection` 恢复原身份。临时网络错误和读取超时按 1–15 秒间隔自动重试，读取单次最多等待十秒；恢复前台或网络在线时可提前重试。凭据库无法读取、配置错误与明确失效的授权保留原记录，提供相应处理入口。连接详情和重新配对放在展开项中，不把清除配对作为默认操作。选择另一个网络时暂停原连接读取，原凭据等新连接保存后才替换。

当连接地址与本机管理的 Hub 一致且服务已停止时，提供“启动服务并重试”；启动沿用当前设备配置和原输入身份，不调用本机输入配对。启动页突出这一实际可执行的动作，网络重试作为辅助操作。管理层在停止状态也返回统一生成的本机 Hub 地址，页面不自行拼装监听地址。

首次配置突出创建/加入网络和 Hub 监听端口；电脑名称可留空，复用本机管理层的系统名称。执行开关和模型请求转发进入高级设置。主按钮依次保存配置、启动服务并连接本机工作台；也提供仅保存配置。项目在登录后的 Hub 工作台创建。加入远端网络时先配置本机执行，再用输入端配对码打开输入工作台，两个身份不混用。

本机管理复用设置框架，分为概览、启动设置、连接与维护、数据与更新。打开时自动读取状态；概览只保留服务状态和开始工作的操作。本机设置不显示项目列表、目录或编辑入口；项目统一在登录后的 Hub 工作台管理。设备编号、网络地址与原始状态说明在维护详情中展开。恢复后的页面提供继续连接与启动入口。

监听端口和反向代理设置在有效修改后自动保存，不提供保存按钮；界面显示待保存、正在保存、已保存或错误。连续输入合并提交，保存期间可继续编辑，旧回执不覆盖新值，启动与切换配置等待设置保存完成。发现指定端口已有 MewDex Hub 时提供直接连接，自动核对该 Hub 并显示其登录方式；保持本机配置与服务归属，普通程序占用仍显示端口冲突。

分类切换保留数据任务视图，数据操作进度可从其他分类返回。后台任务仍由本机管理层持有，关闭对话框后可重新查询。成功读到没有后台操作时不再每秒启动查询进程；进行中的操作和待确认回执继续更新。

视图通过 `useLocalDevice` 共用本机服务操作；配置与服务规则继续归 Go 管理层，网络 SDK 不引用这些桌面模块。项目选择与编辑属于登录后的 Hub 工作台。

“已有数据 / 数据与更新”提供继续使用已有配置：通过原生文件选择器选择本机 `device.json`，先显示设备与服务状态，再确认工作台使用的位置。设置只保存目录指针，配置、模型账号和历史留在原处；切换不会启动、停止服务或更换当前输入连接。也可以预览并返回默认目录。切换后重新建立本机管理视图，启动、停止、自启动和数据操作继续使用同一 Go 管理接口。有数据任务时暂停切换；开发环境明确指定目录时保留该启动范围。

## 键盘

设置、快速切换、搜索、项目文件、附件预览、任务与请求和记录等由状态直接打开的窗口，共用 `useDialogReturnFocus` 记住原入口。取消或关闭后回到仍存在的原控件；嵌套预览优先回到父窗口内的按钮，从对话选项转入其他窗口后也可回到主入口。主动切换目标、定位消息或另一个窗口已取得焦点时，关闭动作不把焦点拉回旧位置。重命名继续保留明确传入的原列表项或顶部对话选项按钮。

通用设置中的“输入与键盘”可选择普通对话输入框的发送方式：默认 Enter 发送、Shift+Enter 换行，也可改为 Ctrl+Enter 发送、Enter 换行；Apple 输入端使用对应的 Command 键。偏好随当前网络与输入身份保存在本机，切换执行设备时保持，旧设置首次读取仍使用原 Enter 默认值。输入区提示和设置中的说明使用相同规则；触屏回车继续换行，点按发送或组合键发送。组词期间、Shift 或 Alt 组合不会触发普通输入发送。

| 操作                 | 快捷键              |
| -------------------- | ------------------- |
| 搜索设备、项目与对话 | Ctrl+K              |
| 查找当前对话内容     | Ctrl+F              |
| 新对话               | Ctrl+N              |
| 聚焦输入             | Ctrl+L              |
| 显示或隐藏导航       | Ctrl+B              |
| 打开或关闭终端       | Ctrl+J              |
| 查看任务与请求         | Ctrl+Shift+J        |
| 设置                 | Ctrl+,              |
| 发送 / 换行          | 按输入与键盘设置    |

快速切换支持方向键与回车。对话框内继续使用其本身的键盘操作；输入法组词期间不触发提交。

焦点位于输出面板时，Ctrl+F 查找当前输出；其他对话区域继续查找当前对话文字。

文本附件或项目文件预览打开时，Ctrl+F 查找当前预览内容。
